🔑 Cuenta + clave de Perplexity

Perplexity es la fase de investigación: es quien busca en internet los datos actuales de la empresa. La clave es gratuita y te lleva unos 2 minutos. Es lo que mantiene actualizados los entregables actualizados — no inventados.

1

Crear una cuenta

Accede a perplexity.ai y crea una cuenta gratuita.

2

Generar la clave

Ve a Settings → API y haz clic en "Generate API Key". La clave comienza con pplx-.

3

Guardar para el .env

Copia y guarda en un lugar seguro. Cuando Claude Code arme el .env, la pegas ahí.

// .env — primera línea

PERPLEXITY_API_KEY=pplx-xxxxxxxxxxxxxxxxxxxx

💡 Por qué importa investigar en vivo

Al ejecutarse en 2026, Perplexity busca datos de 2026. Si una herramienta fue reemplazada o surgió un modelo mejor, las recomendaciones lo reflejan. Eso es lo que distingue un diagnóstico actualizado de un informe genérico que queda obsoleto en semanas.

✨ Cuenta + clave de Gemini

Gemini 2.5 Flash es la fase de síntesis: el motor de escritura que genera los 15 documentos. Se eligió por ser barato y con contexto enorme — es lo que hace posible un paquete completo por menos de US$1. La clave también es gratuita.

1

Abrir AI Studio

Accede a aistudio.google.com/apikey e inicia sesión con tu cuenta de Google.

2

Crear la clave

Haz clic en "Create API Key". La clave comienza con AIzaSy.

3

Completar el .env

Guarda la clave. Es la segunda línea del .env, junto a Perplexity.

// .env — completo

PERPLEXITY_API_KEY=pplx-xxxxxxxxxxxxxxxxxxxx
GEMINI_API_KEY=AIzaSyxxxxxxxxxxxxxxxxxxxxxxxxx

📥 Clonar y ejecutar el repo

Con las claves listas, es hora de descargar la Fábrica y ponerla en marcha. Puedes pedirle todo a Claude Code, pero conviene conocer los comandos básicos para saber qué está pasando. Al final, la interfaz se abre en localhost:8888.

1

Clona el repositorio

Descarga el proyecto ai-strategy-factory para tu máquina.

2

Ejecutar la configuración

O setup.py crea el entorno, instala dependencias y prepara el .env. Funciona en Windows, macOS y Linux.

3

Iniciar la webapp

La interfaz se abre sola en el navegador en localhost:8888. Escribe el nombre de una empresa y haz clic en iniciar.

// lo que Claude Code ejecuta por ti

git clone https://github.com/inematds/ai-strategy-factory
cd ai-strategy-factory
python setup.py            # cria venv, instala, prepara .env
# (cole suas chaves no .env)
python -m strategy_factory.webapp   # → http://localhost:8888

💡 Si el puerto está ocupado

La webapp encuentra automáticamente un puerto disponible. Si quieres fijar otro, pídeselo a Claude Code o ejecuta python -m strategy_factory.webapp --port 9000. En macOS, el puerto 5000 lo usa AirPlay; por eso el valor predeterminado es 8888.

🧮 Gestión de costos

El bajo costo es lo que mantiene alta la rentabilidad. La Fábrica tiene dos modos de investigación y tú eliges en tiempo real según el presupuesto. La diferencia es grande: quick cuesta ~US$0,05; deep cuesta ~US$0,50.

⚡ Modo quick

~9 queries en el modelo sonar. Evaluación rápida en 2-3 minutos, ~US$0,05. Es el modo de tu Misión de hoy.

🔬 Modo deep

~18 queries con sonar-pro. Investigación completa en 5-10 minutos, ~US$0,50. Úsalo cuando el cliente sea grande.

💡 Divide las solicitudes grandes

La documentación cuesta pocos tokens: incluso con un plan básico puedes hacer mucho si divides las solicitudes. Empieza siempre con quick: entrega un paquete completo por unos centavos, y solo pasa a deep cuando el caso lo justifique.
