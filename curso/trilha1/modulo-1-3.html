🔑 Conta + chave Perplexity

A Perplexity é a fase de pesquisa: é ela que busca os fatos atuais da empresa na internet. A chave é gratuita e leva uns 2 minutos. É o que mantém os entregáveis atualizados — não inventados.

1

Criar conta

Acesse perplexity.ai e crie uma conta gratuita.

2

Gerar a chave

Vá em Settings → API e clique em "Generate API Key". A chave começa com pplx-.

3

Guardar para o .env

Copie e guarde num lugar seguro. Quando o Claude Code montar o .env, você cola ela ali.

// .env — primeira linha

PERPLEXITY_API_KEY=pplx-xxxxxxxxxxxxxxxxxxxx

💡 Por que pesquisa ao vivo importa

Rodando em 2026, a Perplexity busca dados de 2026. Se uma ferramenta foi substituída ou um modelo melhor surgiu, as recomendações refletem isso. É o que separa um diagnóstico vivo de um relatório genérico que envelhece em semanas.

✨ Conta + chave Gemini

O Gemini 2.5 Flash é a fase de síntese: é o motor de escrita que gera os 15 documentos. Foi escolhido por ser barato e com contexto gigante — é o que viabiliza um pacote inteiro por menos de US$1. A chave também é gratuita.

1

Abrir o AI Studio

Acesse aistudio.google.com/apikey e entre com sua conta Google.

2

Criar a chave

Clique em "Create API Key". A chave começa com AIzaSy.

3

Completar o .env

Guarde a chave. Ela é a segunda linha do .env, ao lado da Perplexity.

// .env — completo

PERPLEXITY_API_KEY=pplx-xxxxxxxxxxxxxxxxxxxx
GEMINI_API_KEY=AIzaSyxxxxxxxxxxxxxxxxxxxxxxxxx

✓ Por que Gemini 2.5 Flash

  • ✓Custo de entrada baixíssimo (US$0,075/1M tokens)
  • ✓Contexto gigante — cabe muita pesquisa de uma vez
  • ✓Rápido o bastante para 15 documentos seguidos

✗ Cuidados com a chave

  • ✗Nunca colar a chave direto no código
  • ✗Nunca commitar o .env no Git

📥 Clonar e rodar o repo

Com as chaves em mãos, é hora de baixar a Fábrica e subi-la. Você pode pedir tudo ao Claude Code — mas vale conhecer os comandos por baixo, para saber o que está acontecendo. Ao fim, a interface abre em localhost:8888.

1

Clonar o repositório

Baixa o projeto ai-strategy-factory para a sua máquina.

2

Rodar o setup

O setup.py cria o ambiente, instala dependências e prepara o .env. Funciona em Windows, macOS e Linux.

3

Subir a webapp

A interface abre sozinha no navegador em localhost:8888. Digite o nome de uma empresa e clique em iniciar.

// o que o Claude Code roda por você

git clone https://github.com/inematds/ai-strategy-factory
cd ai-strategy-factory
python setup.py            # cria venv, instala, prepara .env
# (cole suas chaves no .env)
python -m strategy_factory.webapp   # → http://localhost:8888

💡 Se a porta estiver ocupada

A webapp acha uma porta livre automaticamente. Se quiser fixar outra, peça ao Claude Code ou rode python -m strategy_factory.webapp --port 9000. No macOS a porta 5000 é da AirPlay — por isso o padrão é 8888.

🧮 Gestão de custo

Custo baixo é o que mantém a margem alta. A Fábrica tem dois modos de pesquisa, e você escolhe em tempo real conforme o orçamento. A diferença é grande: quick custa ~US$0,05; deep custa ~US$0,50.

⚡ Modo quick

~9 queries no modelo sonar. Avaliação rápida em 2-3 minutos, ~US$0,05. É o modo da sua Missão de hoje.

🔬 Modo deep

~18 queries com sonar-pro. Investigação completa em 5-10 minutos, ~US$0,50. Use quando o cliente é grande.

💡 Divida pedidos grandes

Documentação é barata em tokens — mesmo num plano básico dá para fazer muito se você dividir os pedidos. Comece sempre no quick: ele entrega um pacote completo por centavos, e você só sobe para o deep quando o caso justificar.
